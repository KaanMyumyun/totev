# Система за управление на автопарк

Курсов проект по дисциплина „Информационни системи“ – **Вариант 19**.

Уеб приложение за фирма с множество превозни средства (служебни автомобили, бусове, камиони). Системата пази регистър на МПС, план за поддръжка с напомняния по дата и по пробег, история на ремонтите и разходите (гориво, сервиз, застраховки), данни за шофьорите и кой кога е ползвал всяко МПС.

## Основни възможности

| Област | Какво предлага |
|---|---|
| Регистър на МПС | рег. номер (проверка на българския формат, латиница → кирилица), марка/модел, година, тип, гориво, VIN, пробег, статус (активно / в ремонт / спряно от движение), отговорен шофьор |
| План за поддръжка | периодични дейности на всеки N км и/или N дни (масло, технически преглед, гуми, спирачки, тахограф…), индивидуален план за всяко МПС |
| Напомняния | бутон **„Провери обслужване“** и табло: просрочени и предстоящи дейности (по дата или пробег – което настъпи първо), изтичащи застраховки и шофьорски книжки, прогнозна дата по среден дневен пробег, експорт в календар (.ics) |
| История | ремонти и обслужвания (дата, описание, цена, километраж), зареждания (количество, единична цена, автоматична сума), курсове, отчети на километража |
| Шофьори | списък, книжки и категории, поверени МПС, история на ползване |
| Справки | график на обслужванията, разходи по МПС за период (с графика), неактивни МПС, разход на гориво (л/100 км), ползване по шофьори; CSV за Excel |
| Сигурност | вход с роли (администратор, мениджър, механик, логистик), заключване след 5 грешни опита, CSRF, CSP, журнал на действията |

## Технологии

Python 3.12+ (тестван с 3.14) · Flask 3.1 · SQLAlchemy 2 · SQLite · Flask-WTF · Flask-Login · Bootstrap 5.3 · Chart.js 4 · pytest · gunicorn · Docker.

Всички CSS/JS библиотеки са локално в `avtopark/static/vendor`, така че приложението работи и без интернет.

## Бърз старт (локално)

```bash
python3 -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt

flask --app avtopark seed-demo --yes # база с демонстрационен автопарк
flask --app avtopark run             # http://127.0.0.1:5000
```

Демо потребители (парола `Demo1234`):

| Потребител | Роля | Права |
|---|---|---|
| `admin` | Администратор | всичко, вкл. потребители и журнал |
| `manager` | Мениджър | всички данни, отчети за разходи, изтриване |
| `mechanic` | Механик | ремонти, обслужвания, план за поддръжка, статус на МПС |
| `logistic` | Логистик | гориво, курсове (отпускане/връщане), шофьори |

За празна база вместо демо данни: `flask --app avtopark init-db` (пита за парола на администратора).

## Тестове

```bash
pytest                       # 154 теста
pytest --cov=avtopark        # с покритие на кода (~89 %)
```

Тестовете използват отделна временна база и покриват бизнес логиката (напомняния, гранични стойности, километраж, разход на гориво, разходи), целостта на данните (външни ключове, CHECK, уникалност), интерфейса (CRUD, роли, грешни данни) и сигурността (CSRF, XSS, SQL injection, заключване на профил, open redirect, CSV injection, резервни копия).

## Внедряване с Docker

```bash
cp .env.example .env         # задайте SECRET_KEY и ADMIN_PASSWORD
docker compose up -d --build # http://localhost:8000
```

* `web` – gunicorn с 3 процеса, `restart: unless-stopped` и проверка `/health` (HEALTHCHECK);
* `backup` – всеки ден прави резервно копие в `./backups` и пази последните `BACKUP_KEEP` копия;
* базата е във volume `avtopark-data` и не се губи при обновяване на контейнера;
* за достъп отвън – зад reverse proxy (nginx, Caddy) с HTTPS и `SESSION_COOKIE_SECURE=1`.

## Команди

| Команда | Описание |
|---|---|
| `flask --app avtopark init-db` | създава таблиците, видовете дейности и първия администратор |
| `flask --app avtopark seed-demo --yes` | изтрива базата и зарежда демо данни |
| `flask --app avtopark create-user ИМЕ --role mechanic` | нов потребител |
| `flask --app avtopark backup [--keep 14]` | резервно копие (SQLite online backup) |
| `flask --app avtopark restore ФАЙЛ` | възстановяване (текущата база се запазва преди това) |
| `flask --app avtopark check-reminders` | напомняния в конзолата; код 1 при просрочени (за cron) |

## Структура

```
avtopark/
  __init__.py        фабрика на приложението, защитни HTTP заглавки, обработка на грешки
  models.py          модели и ограничения на базата (ORM)
  forms.py           формуляри и валидация
  permissions.py     роли и права
  services/          бизнес логика: напомняния, километраж, разходи, гориво, курсове, експорт, архив
  views/             уеб слой (blueprints): МПС, поддръжка, гориво, шофьори, курсове, справки…
  templates/         HTML шаблони (Jinja2)
  static/            CSS, JavaScript и локални библиотеки
  seed.py            видове дейности и демо данни
  cli.py             команди
tests/               автоматични тестове (pytest)
docs/                диаграми (PlantUML) и екранни снимки
```

Подробната документация (анализ, UML диаграми, база данни, ръководство на потребителя, тестове, сигурност и внедряване) е в `../Документация_Автопарк.docx`.
